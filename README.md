# AI-Assisted Campus Placement Analytics and Skill-Gap Recommendation Platform

AI-assisted campus placement analytics platform with student profiles, placement data management, skill-gap analysis, analytics, resume parsing, and Gemini-powered career recommendations.

## Purpose
A Streamlit-based campus placement platform designed to organize placement data, perform data-quality and placement analytics, identify student skill gaps for selected roles, and use AI to provide personalized career guidance.

## Technology Stack
- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- Google Gemini API

## Setup Instructions
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python populate_db.py`
5. `streamlit run app.py`
